## Preprocessing (pinned)

### Marrow Ery branch (Fig 3 pipeline)

- `sc.pp.normalize_per_cell` → `palantir.preprocess.log_transform` → `sc.pp.highly_variable_genes(flavor="cell_ranger", n_top_genes=1500)`
- Latent rep: `FactorAnalysis(n_components=30, random_state=SEED)` on HVG-only dense.
- Loadings stored as `varm["fa_loadings"]` (n_genes, 30) — zero-padded for non-HVG rows.
- Pseudotime: `palantir.utils.run_diffusion_maps(pca_key="X_fa")` → `determine_multiscale_space` → `palantir.core.run_palantir(start_cell="Run5_164698952452459", ...)` — Fig 3 recipe.
- **MAGIC imputation** on the Ery-branch subset (r24 pinned) — the imputed matrix is what regulator scoring / archetype gene-projection uses. Without MAGIC, the r24 regulator table is not reproducible.

### LARRY myeloid (Gate 1)

- Raw counts: 130,887 × 25,289 from Klein `stateFate_inVitro_normed_counts.mtx`.
- Filter to `cell_type ∈ {Undifferentiated, Neutrophil, Monocyte}` → 113,612 cells.
- Compute-tractability subsample (documented as amendment `bd6fb0d` in Gate 1 v1 prereg): 12,550 cells = all day-2 clone-labelled (4,550) + 2,000 late Neu + 2,000 late Mono + 2,000 late Undiff + 2,000 day-2 Undiff without clone (seed 0).
- `sc.pp.normalize_total(target_sum=1e4)` + `sc.pp.log1p` + `sc.pp.highly_variable_genes(flavor="seurat", n_top_genes=2000)` on the myeloid subset.
- `sc.pp.scale(max_value=10, zero_center=True)` on HVG.
- Latent reps: `FactorAnalysis(n_components=30, random_state=0, max_iter=200)` (Gate 1 v2 E_FA); `sc.tl.pca(n_comps=30, svd_solver="arpack", zero_center=True)` (Gate 1 v2 E_PCA); `scvi.model.SCVI(n_latent=30, n_layers=2, n_hidden=128).train(max_epochs=200, early_stopping=True, batch_size=1024)` on raw counts (Gate 1 v2 E_scVI).
- Palantir pseudotime on `X_FA`, start = min-SPRING-x day-2 Undiff cell.

### LARRY day-2 (Gate 3 strict)

- FULL day-2 subset (28,249 cells), no compute subsample.
- `sc.pp.normalize_total(1e4)` → `sc.pp.log1p` → `sc.pp.highly_variable_genes(flavor="seurat", n_top_genes=2000, subset)` → `sc.pp.scale(max_value=10, zero_center=True)` — all fit on day-2 cells only.
- `FactorAnalysis(n_components=30, random_state=0, max_iter=200)` → E30 features per cell.
- k-NN k=50 in FA30 space via `sklearn.neighbors.NearestNeighbors(algorithm="brute")`.
- Palantir pseudotime for pseudotime positive control.

### scNT-seq neuron labelling (Gate 2)

- `time` column converted from minutes to hours (`adata.obs["time"] /= 60`).
- `dyn.pp.recipe_monocle(tkey="time", experiment_type="one-shot", n_top_genes=2000, keep_filtered_cells=True)`.
- `dyn.tl.moments(adata)`. (Dynamo's kinetic `dyn.tl.dynamics` returns NaN velocities on this dataset because `time` encodes post-stimulation time not labelling duration — noted in `PREREG_Gate2` amendment `6f1d1cb`.)
- Reference velocity: `v_ref = log1p(M_n_hvg) @ PCs_hvg` (labelling-projected).

## scJDO model parameters (all fits reported in the paper)

- `hidden = 256`, `depth = 4`, `use_spectral_norm = True`.
- `sigma = 0.10` (denoising-score-matching perturbation noise scale).
- `alpha_control = 0.001` (control-energy regulariser, default).
- `bandwidth = "auto"` (adaptive selection via the bootstrap-reproducibility × peak-contrast × peak-localisation score).
- `windowing = "kernel"` (Gaussian kernel; NOT the legacy fixed-window scheme).
- `n_archetypes = K = 5`, `n_restarts = 5` for semi-NMF.
- `batch_size = 512`, learning rate `2e-4`, weight decay `1e-4`, cosine-annealing schedule.
- Per-cell local sigma via `local_sigma(X)`.
- `n_epochs`, `grid_size`, `vel_scale`, `bias_strength` — vary per gate, see individual prereg files.

## Kernel windowing (per Methods equation)

Given per-cell Jacobians `J_i` and pseudotimes `τ_i`, at grid points `τ_c`:

```
J̄(τ_c; h) = Σ_i K_h(τ_i - τ_c) J_i / Σ_i K_h(τ_i - τ_c),   K_h(δ) = exp(-δ²/2h²)
```

The bandwidth `h*` is selected on the grid `(0.01, 0.02, 0.03, 0.05, 0.08, 0.10)` by maximising `S(h) = R(h) · C(h) · L(h)` subject to an effective-sample-size floor `N_eff_min = 30`. See `scjdo/archetypes/windowing.py` for `select_bandwidth`.

## Additive pseudotime-gradient prior (previously "velocity prior")

Called via `vel_scale > 0`. Constructs a per-cell prior `V_pt` by k-NN pseudotime-gradient (`_pseudotime_velocity`, k=15) and adds it to the drift output as `output = f_θ(x, t) + vel_scale × gate(τ) × V_pt`. Same slot accepts an external `V_ref` (used by Gate 2's L arm and the velocity-matching-loss variant in Gate 2 redo).

## Velocity-matching loss (introduced in Gate 2 redo / Task 1)

Added to the standard training objective:

```
L_match = λ_match · mean_i [ 1 − cos(f_θ(x_i, t_i), V_ref_i) ]
```

with `λ_match = 1.0` frozen. Direction-only cosine loss (not MSE) to be scale-invariant.

## Block-permutation null (Gate 0d v2)

Partition [0, 1] into blocks of width `h = adaptive bandwidth`. Permute block ORDER; keep WITHIN-block cell order intact. This preserves the local density-of-cells structure while destroying the alignment of position with global τ. 10 draws per fold, seeded by `fold * 100 + draw`.

## Oracle Jacobian (calibration)

For the synthetic-benchmark Fig 2, the oracle Jacobian is the analytic derivative of the toggle-SDE drift `f(x)` at each cell — used to bound estimator fidelity (`r11` in the pre-r26 record, EVIDENCE_LEDGER EL22).
